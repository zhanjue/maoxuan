# 知行录 · 毛泽东著作知识库（MVP）

《毛泽东选集》第一卷的结构化知识库——**文献工程，不是政治表达**。

## 这是什么

把 17 篇正式出版文本（16.3 万字）拆成可检索、可溯源、可交互的知识库：

- **篇目库**：按时期（第一次国内革命战争 / 第二次国内革命战争）与写作时间组织的 17 篇全文，每段编号
- **概念图谱**：20 个概念节点（实践、矛盾、调查研究、工农武装割据、主要矛盾……），每个节点 = 一句话定义 + 核心要义 + 原话精选（逐字引文，精确到段）+ 思想演变链 + 自问自答
- **矛盾论工具**：交互演示「主要矛盾 / 矛盾主要方面」随阶段的转化——把「读」变成「用」
- **全文检索**：段落级，命中直接跳到段
- **时期轴**：1925—1937 的著作时间线 + 概念演变链
- **经典语录**：31 句短句，覆盖 13 篇，全部从原文按句截取、一字未改，每条带「第 N 段」可点回原文看上下文；书签可收藏常想起的几句（存本机 `localStorage`，不上传），「复制收藏」可整份带走（`data/quotes.json` 由 `scripts/gen_quotes.py` 生成，带逐字断言与段号锚词校验）

## 合规边界（写进站点的硬规则）

1. 文本依据人民出版社《毛泽东选集》第一卷正式出版文本，电子文本核自求是网（qstheory.cn），逐字收录，未作改写
2. 只做阅读与检索工具，**不作历史评价、不涉政治表达**
3. 段号为本库对电子文本的段落编号，非纸质版页码；每条引文可点击出处核对
4. 不收任何未正式出版的文献
5. 语录页只做「按句截取 + 溯源」，不拼接段落、不改标点、不加解读、不排名

## 技术架构

```
mao-kb/
├── scripts/
│   ├── fetch.py         # 抓取求是网选集 HTML（URL 规律：书籍 id + _篇目序号，长文按章节分页）
│   ├── parse2.py        # 按 WORKS 映射聚合分页 → works.json（卷/篇/段/注释）
│   ├── gen_concepts.py  # 概念定义 + 引文关键词定位（模糊回退）→ concepts.json
│   └── build.py         # 生成全站静态 HTML（数据内联，file:// 双击可用）
├── data/
│   ├── works.json       # 17 篇结构化语料
│   ├── concepts.json    # 20 个概念节点 + 46 条溯源引文
│   └── raw/             # 25 个原始 HTML（审计留痕）
└── site/                # 生成的静态站（45 个文件，零依赖）
```

前端为 Ink 纸白主题（参考 Nutlope/hallmark 设计规范）：白纸 + 无相黑 + 一条 teal 只表状态；无 webfont、无外部依赖、无 fetch（所有数据内联）。

## 本地运行

```bash
# 重新生成（改语料/概念后）
python scripts/fetch.py        # 抓取（已有 raw/ 可跳过）
python scripts/parse2.py       # 解析
python scripts/gen_concepts.py # 概念节点
python scripts/build.py        # 生成站点

# 预览
cd site && python -m http.server 8787
# 或直接双击 site/index.html（数据已内联）
```

- 《为争取千百万群众进入抗日民族统一战线而斗争》求是网未收录，第一卷暂缺 1 篇（17/18）
